Свои 3D-модели машин (формат .glb).
1. Положите файл, например taxi.glb, в эту папку.
2. Создайте рядом файл index.json:
   { "car0": { "file": "taxi.glb" }, "car7": { "file": "muscle.glb", "rotY": 1.5708, "scale": 1 } }
   car0 ... car19 — номер машины в гараже. rotY — поворот модели (радианы), чтобы нос смотрел вдоль оси X; scale — масштаб; y — подъём.
3. Пересоберите APK. Если файла нет или он не загрузился, игра использует встроенную модель.
Берите только модели, на которые у вас есть права (свои или с лицензией CC0/CC-BY). Модели из Rocket League использовать нельзя — они защищены авторским правом.
