# Arena Cars

Мобильная 3D-игра: машины на круглой арене выбивают друг друга в лаву. Вид от третьего лица, офлайн против ботов и онлайн до 4 игроков.

## Как получить APK
1. Создай репозиторий на GitHub и загрузи в него ВСЕ файлы из этой папки (включая скрытую папку `.github` — если её не видно, создай файл `.github/workflows/main.yml` на сайте GitHub и вставь содержимое из `main.yml`).
2. Открой **Actions → Build APK → Run workflow** (или сделай push в `main`).
3. Через 5–8 минут APK появится в **Releases** — файл `ArenaCars.apk`. Установи на телефон.

## Мультиплеер (сервер нужно запустить один раз)
Игра ходит на сервер по WebSocket. Сервер — один файл `server/server.js` без зависимостей (Node 18+).
1. Зайди на render.com → **New → Blueprint** → выбери свой репозиторий (файл `render.yaml` уже есть). Тариф Free.
2. Дождись деплоя, скопируй адрес вида `arena-cars-server.onrender.com`.
3. В игре: **⚙ Настройки → Сервер** → вставь адрес → «Проверить» → «Сохранить». (Или впиши адрес в `DEFAULT_SERVER` в `src/net.js` перед сборкой APK — тогда игрокам ничего вводить не придётся.)
4. Дальше: **🌐 Онлайн** → «Быстрая игра» (боты добавятся, если игроков мало), «Создать комнату» (код для друзей) или «Войти» по коду. Вкладка **👥 Друзья**: твой 14-значный ID, поиск по ID, запросы (принять/отклонить, после отказа можно отправить снова).
- Бесплатный Render «засыпает» без нагрузки: первое подключение может занять ~30 секунд. Друзья и профили хранятся в `server/data.json` — на бесплатном Render файл стирается при перезапуске; для постоянного хранения подключи Render Disk и задай переменную `DATA_FILE`.
- Локальная проверка: `node server/server.js` (порт 8080).
- Игра считается на сервере (клиенты шлют только управление), чужие машины показываются с задержкой ~0,1 с. Покупки и уровни хранятся на телефоне.

## Управление
Джойстик — в любом месте своей половины экрана: вверх — вперёд, влево/вправо — поворот (относительно камеры). Правая сторона: кнопка **⤴ прыжок** (перезарядка 1,5 с, кольцо вокруг кнопки показывает готовность) и кнопка способности. На компьютере: WASD/стрелки, пробел — прыжок, E — способность.

## Правила
- 100 здоровья; удары и тараны снимают его. Стены под 45°; заехал разогнавшись — можно вылететь за стену в лаву. Через 40 с арена начинает сужаться и поднимается лава.
- Выбыл — наблюдай: режимы «Авто», «За машиной», «Вокруг», «Сверху», список соперников с здоровьем, камера крутится пальцем.
- Победа: +20 🪙 и +50 опыта. Поражение: +5 🪙 и −5 опыта (уровень может упасть). За новый уровень +10 🪙, на 10/20/…/90 уровнях — ящик 🎁, на 100 — лучшая машина.

## Лобби и гараж
Машина стоит в центре, кнопки по углам. В гараже нажми на машину → «Осмотреть» (справа окно с характеристиками, машину можно крутить на 360°) или «Купить/Выбрать». Ящик: бесплатный или за 400 🪙 — выпадает случайная ещё не купленная машина.

## Свои модели и музыка
- Встроенные модели машин — процедурные (кузов из профиля, стёкла, колёса, фары). Реалистичнее можно положить свои `.glb` — см. `public/models/README.txt`.
- 7 встроенных треков играют в лобби по порядку; свои mp3 — см. `public/music/README.txt`.
- Оригинальные модели и песни Rocket League использовать нельзя (авторские права), поэтому их в игре нет.

## Настройка баланса
- `src/store.js` — награды, опыт; `src/cars.js` — машины и цены; `src/sim.js` — физика, размер арены (`R_FLAT`), прыжок, урон, лава.
